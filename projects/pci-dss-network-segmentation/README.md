# PCI DSS Network Segmentation: Defending the CDE Boundary Under QSA Scrutiny

A payment platform has renewed the same segmentation attestation every year without testing the parts that don't show up on the architecture diagram. This report builds the testing scope a QSA will actually run and names the boundary that fails before an auditor finds it first.

The company is built for this case study. The PCI DSS requirement citations are real and current.

**Framework:** PCI DSS v4.0.1, Requirement 1 (Network Security Controls and CDE Scoping); Requirement 11.4.5 through 11.4.7 (Segmentation Penetration Testing)
**Tags:** PCI DSS, Cybersecurity, GRC Engineering
