# Risk Acceptance Memorandum: Legacy EDI Gateway TLS Encryption Gap

A healthcare claims gateway is stuck on TLS 1.0 while a vendor migration is pending. Walks the full decision: vulnerability, risk, likelihood and impact rating, compensating controls, residual risk, and a recommendation with a forced expiration date.

The company, vendor, and system are built for this case study.

**Framework:** HIPAA Security Rule (45 CFR 164.312(e)(1)), SOC 2 Common Criteria (CC6.7)
