# ISO/IEC 27001:2022 Statement of Applicability: Justifying Control Exclusions for a Remote-First SaaS Company

A consultant-built Statement of Applicability marks all 93 Annex A controls applicable. This document rebuilds it from the actual infrastructure up: which controls apply in full, which apply with the scope narrowed to what the company really operates, and which do not apply at all, with reasoning an auditor can test.

The company is built for this case study.

**Framework:** ISO/IEC 27001:2022, Clause 6.1.3 (Information Security Risk Treatment); Annex A, 93 controls across four themes (Organizational, People, Physical, Technological)
**Tags:** ISO 27001, GRC Engineering, Cybersecurity
