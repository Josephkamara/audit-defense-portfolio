# Multi-Cloud SOX ITGC Control Mapping: AWS and GCP Evidence Sources for a Shared-Responsibility Environment

A company running production across both AWS and GCP tests the same six SOX IT general controls in two environments that expose evidence through completely different native services. This maps each control objective to its real native evidence source in both clouds, works one objective through end to end with actual AWS CLI and gcloud commands, then separates what a script can pull from what a SOX tester still has to judge.

This design sample is built for this case study, not a deployed audit or automation.

**Framework:** SOX Section 404 IT General Controls, tested against native AWS and GCP evidence sources
**Tags:** Cloud Security, GRC Engineering, SOX
